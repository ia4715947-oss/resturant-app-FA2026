# Restaurant App - FA2026 - Iqra Asad

Restaurant Reservation & Management System

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB

## Features
- User Registration / Login
- Menu Browsing
- Table Reservation
- Admin Panel to manage bookings

## How to Run
Server:
cd server
npm install
npm start

Client:
cd client
npm install
npm run dev
